



System Requirements
CITE Lost and Found System
1. Functional Requirements
• Student Registration: The system shall allow students to register an account.
• User Login: The system shall allow registered users to log in according to their assigned access.
• Lost Item Reporting: Students shall be able to report lost items by providing item details.
• Item Information: The system shall store item descriptions, dates, locations, and other relevant details.
• View and Search Items: Users shall be able to view and search available lost-and-found records.
• Item Status: The system shall allow authorized updates to item statuses, such as Lost, Found, Claimed, or Released.
• Database Storage: The system shall store item and account information in a database.
• Logout: Users shall be able to log out securely.
2. Non-Functional Requirements
• Usability: The interface should be simple and easy to understand.
• Security: The system should protect account credentials and restrict access to authorized functions.
• Reliability: The system should store and retrieve records accurately.
• Performance: The system should respond to ordinary user actions within a reasonable time.
• Maintainability: The code should be organized so future improvements can be made.
• Data Integrity: The system should validate required information before saving records.
3. Project Users
• Students: Register, log in, and report lost items.
• Administrator: Review reports and manage lost-and-found records.
4. Project Status
These requirements describe the planned system and should be updated as development progresses.
