CITE Lost and Found System

Project Description

The CITE Lost and Found System is a proposed system for PHINMA Cagayan de Oro College designed to help students report lost items and help administrators manage lost-and-found records.

Project Objectives

- Provide an organized way for students to report lost items.
- Help administrators manage lost-and-found records.
- Store item information in a database.
- Make it easier to search for and identify lost items.

Planned Features

- Student registration
- Lost-item reporting
- Viewing and searching item records
- Administrator login
- Managing and updating item information
- Database integration

Technologies

- Java
- NetBeans IDE
- XAMPP
- MySQL

Project Status

In Development

Institution

PHINMA Cagayan de Oro College
