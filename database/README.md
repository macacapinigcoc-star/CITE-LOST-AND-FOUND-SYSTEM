Database Documentation
CITE Lost and Found System
Database Overview
The database will store information needed by the CITE Lost and Found System at PHINMA Cagayan de Oro College.
Planned Database Tables
1. Students
• Student ID
• Full name
• Email
• Password hash

2. Lost and Found Items
• Item ID
• Item name
• Description
• Location
• Date reported
• Item status
• Reported by
Database Technology
MySQL, managed through XAMPP and phpMyAdmin.
Security
• Passwords should be stored as secure hashes, not plain text.
• Database access should be restricted to authorized users.
• Personal information should be protected.
Project Status
Planned. The database tables and fields will be updated during implementation.
